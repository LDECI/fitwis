# 健身APP

一个基于“AI 与健身行业结合方式”理念的前端示例应用，主要用于演示如何通过表单收集用户信息并生成个性化健身与 AI 辅助建议。

## 功能概览

- 填写基础信息：年龄、性别、训练经验、每周可训练天数等
- 选择健身目标：减脂、增肌、塑形、综合健康
- 生成建议：
  - 训练频率与每次时长建议
  - 一周示例训练计划（按天拆分）
  - AI 赋能方式建议（如：智能课程推荐、动作纠正、数据可视化、社群运营等）

## 文件结构

- `index.html`：主页面结构
- `styles.css`：页面样式
- `app.js`：前端交互逻辑与“智能建议”生成逻辑

## 使用方式

1. 打开文件夹 `健身APP`
2. 直接用浏览器打开 `index.html`
3. 填写表单并点击“生成方案”，即可看到页面中的个性化健身与 AI 结合建议
